# 《Project: ThunderRogue》（代号：雷霆肉鸽）

> 俯视角 2.5D 硬核动作肉鸽 (Top-down ARPG Roguelike) 
> 融合暗黑2/3刷宝爽感、老街机隐藏探索深度与纯动作帧数驱动体系。

---

## 核心设计哲学
1. **纯动作帧数与法力驱动（去 CD 化）**：无技能转圈倒计时，施法频率完全受动作前摇与攻速物理控制，用有限技能点与法力值作为核心收敛；
2. **暗黑2“闪电之怒”级连锁打击**：穿透投射物 ✖ 命中几何级次级电弧爆发，怪越多场面越毁天灭地；
3. **极简即捡即吸（彻底抛弃背包）**：7~8 个暗黑经典部位，爆装即时【替换】或【吸收升品/精炼】，5 色词条池严格锁定部位与护甲种类；
4. **布甲基准负重衰减**：布甲 0 衰减（纯玻璃大炮），重甲攻速移速衰减但大幅压缩控制时长并自带低概率无视强控（纯铁憨憨）；
5. **战术回城与自损保命**：10 秒站桩全屏引怪回城（可反向聚怪），随身自损扣血无差别震飞周围怪群的保命底牌；
6. **老街机隐藏因果与傲慢试金石**：请酒送信物开密道、冒死闯雷道拿雷锤；全魔法免疫+超高物防的“虎牢关吕布”式守门恶兽（击杀只给稀有成就，捍卫硬核动作尊严）。

## 项目路线图 (Milestones)

- [ ] **Phase 1: 战斗与投射物力学核心 (Core Combat & Projectiles)**
  - 动作帧数状态机 (Startup/Active/Recovery/Cancel)
  - 投射物物理管线 (直线、穿透、分裂、射线扫掠碰撞)
  - 闪电之怒几何级连锁电弧模拟
  - 实体软推挤、硬直 (Hitstun) 与卡肉顿帧 (Hitstop)
  - 纯 C# xUnit 自动化单测覆盖

- [ ] **Phase 2: 装备与构筑流转系统 (Equipment & Progression)**
  - 7~8 核心部位模型 (头/链/戒/双持/胸/腿/鞋)
  - 无背包【即捡即用】替换与吸收升品管线
  - 5 色阶梯词条池 (绿/白/蓝/紫/橙) 与部位专属绑定
  - 附魔洗练与数值区间 Roll 机制
  - 布甲/皮甲/轻甲/重甲物理负面衰减计算器

- [ ] **Phase 3: 角色技能、回城与自损保命道具 (Skills & Tactics)**
  - 有限技能点分配器与蓝量/回蓝博弈
  - 10 秒冲天光柱全屏引怪回城仪式
  - 自损扣血无差别击退消弹震爆道具
  - 破法魔免敏捷守门恶兽 AI 行为树

- [ ] **Phase 4: 地牢生成与事件高潮 (Dungeon & Events)**
  - 暗黑2式房间模块拼接与支线宝箱拓扑图
  - 暗黑3式诅咒宝箱 30 秒突发怪潮事件
  - 街机式恩义分支 (送礼反水开密室) 与险道神兵试炼 (雷道拿雷锤)

- [ ] **Phase 5: Godot 4 (.NET 8) 渲染与表现层装配**
  - 2.5D Top-down 摄像机与鼠标瞄准/WASD 移动
  - 弹道粒子、连锁电弧特效与屏幕微震
  - 极简即时换装与洗练 UI
